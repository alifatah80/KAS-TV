KAS TV Android project — وەشانی 1.0

ئەمە سەرچاوەی پڕۆژەی Android ـە، APK ـی ئامادە نییە.
تایبەتمەندییە سەرەتاییەکان:
- M3U/M3U8 URL و فایل
- پلەیەری Media3/ExoPlayer بۆ پەخشکردنی ستریمە گونجاوەکان
- خانەکانی Xtream (بارکردنی M3U بە شێوازی get.php)
- خانەکانی MAC/Portal تەنها وەک ڕووکار؛ پەیوەندیی گشتی بۆ هەموو دابینکەرێک نییە.
- بنەمای ڕووکار بۆ مۆبایل و Android TV.

چۆن APK دروست بکەیت بە مۆبایل:
1) ZIP ـەکە لە GitHub repository ـێکی نوێدا Upload بکە و فایلەکان لە ڕەگی repository دابنێ.
2) بچۆ بۆ Actions > Build KAS TV APK > Run workflow.
3) دوای تەواوبوونی build، artifact ـی KAS-TV-debug-apk دابگرە و ZIP ـەکە Extract بکە؛ app-debug.apk تێدایە.
4) APK ـەکە تەنها لە مۆڵەتی دامەزراندنی سەرچاوەی متمانەپێکراو دابمەزرێنە.

تێبینی:
- ئەم کۆدە وەشانی سەرەتاییە و لە ژینگەی Android SDK ـدا لێرە کۆمپایل نەکراوە؛ پێش بەکارهێنانی ڕاستەقینە build و تاقیکردنەوەی پێویستە.
- Xtream endpoint و CORS/SSL و پڕۆتۆکۆلی دابینکەر دەتوانن کاریگەرییان هەبێت.
- MAC/Portal یەک ستانداردی گشتی نییە؛ بۆ پشتگیریی ڕاستەقینە پێویستە پڕۆتۆکۆلی دابینکەری مۆڵەتپێدراو بزانرێت.
- ئەپەکە بە تەنها هیچ کەناڵێک نادات؛ تەنها playlist/خزمەتگوزارییەکی یاسایی و مۆڵەتپێدراو بەکاربهێنە.
- داتاکانی چوونەژوورەوە لەگەڵ کەس هاوبەش مەکە.
